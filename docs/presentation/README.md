# Technical Defense & Presentation Assets

This directory contains the presentation slide deck, slide generation tooling, and extracted visual assets for the Next-Gen Control Plane project defense.

## Contents

- **`Control_Plane_Final_Presentation_20Slides.pptx`**: Complete 20-slide technical presentation deck covering system architecture, Raft consensus, mTLS security, predictive fault tolerance, dynamic workload scheduling, and benchmark results.
- **`generate_final_presentation.py`**: Automated Python script leveraging `python-pptx` to generate the presentation deck programmatically with consistent visual hierarchy, high-contrast typography, and structured content cards.
- **`extracted/`**: Directory containing extracted presentation slide graphics, architecture diagrams, and test assets.

> **Note:** These artifacts are preserved for academic defense, conference talks, and architecture reviews. Core production runtime services (`java-control-plane`, `web-ui`, `desktop-ui`, `cli`, and `python-predictor`) operate independently of these presentation files.
